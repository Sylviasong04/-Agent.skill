# 逐页讲解课件 · lecture-review

轻量的 Codex Skill：阅读 PPT、PPTX 或 PDF，逐页生成中文讲解，保存为一个 Markdown，并直接接入已有知页本地网页知识库。

## 安装

下载仓库，将 `lecture-review` 文件夹复制到 `~/.codex/skills/`，然后重新打开对话。

## 使用

在已有知页项目的工作区上传课件，输入：

> 使用 $lecture-review 阅读此 PPT，并逐页给我讲解。

默认通过现有导入器登记课件，将完整讲解写入该文档的 `notes.md`；逐页模式和整页模式共用这个文件。刷新已有页面即可读取。知识库不在当前工作区时提供其路径。

流程保留必要的图表阅读和页码对应检查，不默认批量转图片、扫描目录或执行全站测试。仅需对话讲解时直接说明。
